# 委託紀錄簿

記錄每一筆繪師委託、金額與完成插圖的網頁 App。可加到 iPhone 主畫面，像 App 一樣使用，也能離線開啟。

- 所有紀錄和插圖只存在使用者自己的裝置（瀏覽器的 IndexedDB），不會上傳到任何伺服器。
- 可依日期或金額排序、依繪師篩選、搜尋。
- 可匯出圖片（JPG）、PDF、CSV、圖文網頁（HTML），並可下載完整備份檔與還原。

## 加到 iPhone 主畫面

1. 用 **Safari** 打開這個網站。
2. 點下方的「分享」按鈕 →「加入主畫面」→「新增」。
3. 之後從主畫面的「委託紀錄簿」圖示開啟。

> 刪除主畫面圖示時，裡面的紀錄也會一起刪除，請先下載備份檔。

## 檔案說明

- `index.html`：App 本體
- `manifest.webmanifest`：App 名稱、圖示設定
- `sw.js`：離線快取（只快取 App 檔案，不碰使用者資料）
- `icons/`：App 圖示

## 更新 App

修改檔案後重新上傳即可。若想讓已安裝的人盡快拿到新版，請把 `sw.js` 裡的 `VERSION` 改成新的值（例如 `"v2"`）。
